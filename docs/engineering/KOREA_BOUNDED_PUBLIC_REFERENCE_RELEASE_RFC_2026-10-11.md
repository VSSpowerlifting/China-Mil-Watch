# RFC — five-record South Korea MND reference pilot (NOT APPROVED)

**October 11, 2026.** Proposal only. The Korea Desk remains **shadow/private**. This RFC itself makes no release change. Subsequent implementation PRs have created a private, noindex, real-site template preview and secure reviewer handoff; none authorizes public activation. Related: [Korea Desk Phase 2 #221](https://github.com/VSSpowerlifting/China-Mil-Watch/issues/221), [private Korea reader PR #410](https://github.com/VSSpowerlifting/China-Mil-Watch/pull/410), [real HWPX verification PR #411](https://github.com/VSSpowerlifting/China-Mil-Watch/pull/411).

## Goal / smallest useful release

A manually adjudicated **five-or-fewer-record official reference list** of Ministry of National Defense (**국방부**) releases **republished by Korea Policy Briefing**, with no copied HWPX, images or other original bodies.

Label the surface **“South Korea / Ministry of National Defense — Policy Briefing republications (limited reference pilot)”**, with a visible fixed review date. It is not a full national desk, independent Korea military intelligence, new collector or promise of real-time coverage.

**Maximum initial allowlist:** `156783602`, `156783708`, `156784196`, `156784297`, `156784652`. Publish **only individually approved rows**, possibly zero. Disallow any future IDs or DAPA `B00008`.

## Proposed public row shape (after ALL gates pass)

- Original Korean headline and a short **human-corrected**, source-attributed English descriptor.
- Canonical `https://www.korea.kr/briefing/pressReleaseView.do?newsId=...` link and correct publisher/issuer labels.
- `portal_publication_date`, `document_distribution_date`, and optional `event_date`, independently verified and never merged. For `156784297`, use **portal Oct 6 / distribution Oct 4**.
- Source ID, precise source content SHA, original source URL, review timestamp, clear license attribution and publisher policy link.
- A note such as **“Five curated references from a single republished MND source family; not comprehensive Korea coverage.”**

**Explicitly absent:** full Korean bodies, copied quotes/excerpts, source HWPX/PDF files, translated whole documents, media, military seals/logos, autogenerated interpretation, email send, live-feed status, historical bulk ingestion, automatic Sunday manuscript claims.

## Sequence of hard release gates

### R0 — Completed (not publication approval)
- The existing five archived Korean original-text rows were read and interpreted in Korean, including dates, statements and ambiguous wording. Detailed unsigned notes: `KOREA_FIVE_ORIGINAL_SEMANTIC_REVIEW_2026-10-11.md`.
- [Real-source byte audit](https://github.com/VSSpowerlifting/China-Mil-Watch/actions/runs/38179731270) confirmed five archived HWPX re-extractions, source-text SHA parity and published ledger continuity.
- Each of the five publisher pages was separately observed to contain **KOGL Type 1 text-only** attribution language. Scope and holds: `KOREA_FIVE_SOURCE_RIGHTS_DISPOSITIONS_2026-10-11.md`.
- **Human independent reviewer = NOT SIGNED. Rights owner clearance = NOT SIGNED. Public approval = NOT GIVEN.**

### R1 — Qualified human Korean-source review
For **each candidate row**, a Korean-language competent human compares the genuine rendered HWPX against the source original and existing extraction; verifies names, dates, paragraph/table order, military terms and modal language; reviews first-party publisher notice/attachment scope; and records:
`source_id`, `state_commit`, `content_sha256`, `document_capture_sha256`, `reviewer_identity`, `reviewed_utc`, `interpretation_result`, `source_rights_result`, `allowed_public_use`, `corrections`.

No guessed reviewer, no bulk rubber-stamp, no inheritance of rights from neighboring records; any ambiguity leads to **per-record HOLD**. Keep signed details in suitably access-controlled private review storage, not a public PR or Actions artifact. Independent rights/compliance owner then makes and records a separate final use-type decision. A model's Korean-reading notes do not satisfy this gate.

### R2 — Private static preview, not public publication
A future separate build PR creates a **disabled/manual-only** static preview from exactly the approved allowlist. The renderer must fail closed on missing source SHA, wrong issuer/host, changed content SHA, absent signed review and rights decision, wrong release/event chronology or unexpected sixth record. No automatic source publishing, public route, public index, RSS, search indexing, background cron, mass copy or deploy.

Tests must cover the **October 4 versus October 6 chronology**, no automated “deployed” assertion for the Cheonghae Unit, no manufactured missile intercept, no made-up McCormick shipbuilding deal, and the exclusion of HWPX/images. Verify strict metadata projection and reviewer/rights fields.

### R3 — Separate owner-authorized public release
Only after R1 and R2 pass, review exact-head CI, one or more accessible desktop/mobile previews, source/rights/citation QA, protected production DB/output hash preservation and owner signature; then open a **separate release PR**. No public change is implied by merging this RFC, the private reader, or the machine attestation.

The existing site builder currently refuses a `public=true` Korea registry change; the eventual separately authorized public release PR must consciously replace that deny-by-default guard after the approvals. A release must be easy to disable: a single bounded publication feature gate, a fixed list of reviewed source SHAs, and **hide-on-drift / takedown** handling. If original text changes, the publisher withdraws a notice, media leaks into output, a reviewer withdraws approval or any misleading claim is found, hide that record pending re-review.

## Explicit non-goals

No direct MND crawler, no DAPA activation, no new schedules, no automatic Korean translation, no institutional expansion, no claim of 7/14/30-day qualification, no public Korea-wide record count, no “live Korea Desk” banner, no model-driven Sunday inclusion, no publication before independent human review.

**Stop condition:** This document is an editorial/engineering specification, not a release decision. The first critical missing evidence remains genuine independent Korean-language visual source review, rights-reviewed output decisions, and authenticated per-record owner approval. Do not deploy on the strength of model analysis, a license label, a passed machine HWPX audit, or a structurally populated JSON alone.
