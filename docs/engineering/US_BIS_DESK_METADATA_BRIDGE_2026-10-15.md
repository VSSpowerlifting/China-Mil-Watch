# BIS U.S. Desk official metadata-only display bridge — held source work

The existing public U.S. Desk carries live USCC congressional and Treasury
executive official URL/date/issuer link lists plus nine static PACOM outbound
references. BIS is a Commerce bureau and remains a separate source. This
change conditionally reads ONLY BIS records held in the distinct scheduled-
run-attested production metadata table built by the parent #705 source phase.

An absent or empty table returns no BIS link list. No HTML section is shown,
and existing U.S. Desk wording and records remain unchanged. A separately
authenticated and admitted metadata row appears as a neutral link, publisher
date, fixed Commerce/BIS issuer, and a direct outbound official-source
reference. It is neither an IPR-authored research article nor a source-body
record. The status description changes only when those BIS records genuinely
exist, and explicitly preserves PACOM access-blocked and DVIDS-paused status.

This PR is stacked on #705 and does NOT itself import or admit a receipt,
modify pla_watch.db, create generated output, deploy Pages, promote any desk,
grant publisher rights, preserve original BIS documents, translate source
material or synthesize substantive analysis. There are no BIS live records yet.

Release must be a separate guarded workflow: independently authenticate a
genuine BIS scheduled source run and exact preserved Git observation, admit
only metadata to the production SQLite, render/check the U.S. Desk HTML, stage
ONLY pla_watch.db and output/us-indopacific.html on current main, publish
ONLY us-indopacific.html to gh-pages, and confirm the exact deployed metadata
readback. Run source branch and main SHA stability checks before publication.
Never inflate IPR's original article totals or silently replace the already
live USCC/Treasury and PACOM references.

The source-free test exercises a synthetic Jinja copy of the actual template
fragment against disposable attested SQLite metadata rows. No public records
or site artifacts are generated by these tests.
