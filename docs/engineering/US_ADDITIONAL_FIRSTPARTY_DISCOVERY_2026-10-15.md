# Other U.S. first-party family access canary — October 15, 2026

The U.S. Desk has a proven live USCC congressional commission link/date/issuer pipeline, but PACOM and Navy fleet origin sites previously returned inaccessible robots policies. Expansion must use independently attributable official publishers, not DVIDS unit tags masquerading as command-issued text.

The bounded read-only canary tests seven plausible federal host/listing pairs: Navy, Defense Department, Treasury, State, GAO, BIS and DHS. Each receives one `robots.txt` request and **at most one** first-party listing request if the current policy allows it. No URLs beyond that listing are requested, no files saved, no access bypasses or retries. Every positive result is only *technical retrieval feasibility*, never a qualified collection day, completeness, reuse permission or automatic public admission.

Prioritize Navy and Defense if genuinely accessible, followed by State and Treasury for Indo-Pacific strategic/diplomatic/economic-security measures. Discard inaccessible/ambiguous hosts and avoid building unsupported parser assumptions.

The next implementation must be source-family-specific, preserve exact issuer/date/source IDs and use an isolated immutable observation history before any production promotion. The same URL/date/issuer-only standing approval may be used for metadata publication; never copy headlines, original bodies or media without separately documented reuse decisions.
