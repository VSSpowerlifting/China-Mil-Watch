# Vietnam MPS — October 10 historic/current shadow-source continuity

This private comparison answers a narrow evidence question: **Are the three
Vietnam Ministry of Public Security source rows originally selected for
October 10 still represented with the same archived source versions in the
newer MPS shadow database?** It does not claim that any currently published
ministry webpage has been independently re-opened, that an original-language
review was performed, or that source reproduction/model rights exist.

historical shadow Git commits:

## What is actually checked

The command consumes the repository's validated Oct 10 research catalog,
**two separately generated historical shadow review queues** and one
newer current shadow review queue. It checks the historical queue's
exact ID, publisher URL, publication date, source content SHA-256,
language/scope and eligibility blockers against the Oct 10 research packet.
It then compares the same identity to the newer queue's URL/date,
captured version SHA, first capture digest, source title, body status
and any new machine hold. Absence becomes
`source_missing_from_newer_shadow_not_publisher_silence`, not proof that
the ministry issued no statement.

Each input queue must be generated by
`scripts.prepare_vietnam_mps_review_queue.prepare` from the **actual
Git commit of the isolated state branch** using independent Git ancestry,
ledger, capture and SQLite validation. A queue's canonical self-hash
only detects subsequent changes; a synthetically recreated queue
does **not** constitute source provenance. The focused in-repository CI
performs this export from the real remote shadow branch, checks the
historical commits' ancestry against the newer branch, then compares.
It reports only typed IDs, Git state hashes, source content hashes and
changed *field names*; no publisher URL, article body or analyst synopsis.

## Operator command

Use a separately fetched, already available
`shadow/vietnam-mps-foreign-affairs` branch with the exact older Git
objects. Generate each queue separately using the existing verified
exporter, into **three fresh private folders** outside the source
repository. Do not create or hand-edit the queue JSON manually.

```bash
python -m scripts.prepare_vietnam_mps_review_queue \
  --state-repo /path/to/vietnam-mps-state \
  --state-commit 46f6a0e59e25b03868bf7ad600963d6921ee5124 \
  --out-dir /private/mps-oct5

python -m scripts.prepare_vietnam_mps_review_queue \
  --state-repo /path/to/vietnam-mps-state \
  --state-commit c7c13dc7c15d855412afff99db23695dd50e51a5 \
  --out-dir /private/mps-oct7
```

Run the exporter once more against the **exact current shadow branch
HEAD commit SHA**. Then:

```bash
python -m scripts.vietnam_mps_source_version_drift \
  --historical-queue /private/mps-oct5/review_queue.json \
  --historical-queue /private/mps-oct7/review_queue.json \
  --current-queue /private/mps-current/review_queue.json \
  --out /private/mps-oct10-source-version-comparison.json
```

The report must be a **new exclusive mode-0600 file outside Git**.
It cannot be used as an approval docket: all human original checks,
source rights, regional AI use, Dylan delivery, Vietnam production
activation and publication flags are hard-coded false. No public
publisher page is fetched by this audit.

**Important distinction:** an unchanged archived source version does
not establish current publisher originality, finished cross-language
analysis, permission to copy the publisher's article, signed country
desk promotion or permission to publish a regional Brief. The Sunday
pilot has a separate exact-owner-reviewed manuscript attachment digest
gate. Issue #271's original-language/reuse-rights checks remain open.
