# Vietnam ministry pass — written request budget

Written 2026-10-06 UTC, before the first request of this pass. It covers both
the source probes and the live rehearsals. Nothing here may be raised after
the fact; an amendment is written into this file, with its reason, before the
request it allows.

## Rules for every request

- Identity: `ChinaMilWatch-ShadowCollector/0.1 (+https://chinamilwatch.org;
  research archive; contact via site)`, unchanged. Headers: that User-Agent and
  `Accept-Encoding: identity`, nothing else.
- One worker. Probe requests are spaced at least 2 s from the end of the
  previous request to any host, or by a host's published Crawl-delay for this
  agent when it is longer. The spacing is enforced through a lock file, so
  separate probe invocations cannot overlap or crowd one another.
- Timeout 30 s. Bodies are read raw (no decoding) up to 3 MB; a larger body is
  cut off and recorded as truncated.
- A fresh session per request. No cookie is ever sent, no retry is made.
- robots.txt is requested before any other path on a host. Up to five robots
  redirects are followed and logged (RFC 9309 §2.3.1.2). A host whose robots.txt
  is not a readable rules file (a script page, an error, a timeout) gets no
  further request.
- No URL is guessed. A request goes only to robots.txt, the homepage the brief
  names, or a URL published as a link on a page this pass captured (or in an
  `HTTP Location` header).
- Redirects are followed one hop at a time, and only when all of these hold:
  the target is https; its host's robots.txt is read and allows the path; the
  target is not already in the chain; the chain has at most five hops; and the
  hop is not a cookie gate (a 30x back to the same URL that sets a cookie).
- A challenge page is recorded and never answered: no script is run, no cookie
  is returned, no browser is imitated.
- HTTP 429 or 503, or any `Retry-After`, is treated as a published requirement:
  the whole group stops for the rest of the pass and the reason is logged.
- TLS is always verified. A certificate that cannot be verified leaves the
  host unreached; verification is never switched off.
- Only https is requested. If a page publishes only an http link, an amendment
  is written here before that request.
- Outcomes are recorded by mechanism: robots disallow, HTTP 401/403, an edge
  deny page, a script-and-cookie challenge, a cookie gate (30x back to itself),
  a redirect loop, throttling, a TLS failure, or another network error.
- Every response keeps: requested URL, each redirect hop with its `Location`,
  final URL, HTTP status, content type, all response headers, exact byte count,
  SHA-256, UTC request and completion times, and the exact bytes.

(page 2 only if page 1 links it); the official English edition when one is
linked; a published terms or copyright page when one is linked; then varied
article pages from a family that passed listing checks.
