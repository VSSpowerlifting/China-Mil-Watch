US Indo-Pacific Reference Desk

Declared as a reference desk, deliberately bounded: the minimum US institutional output needed to read other desks' framing against a US framing of the same events. It is not a feed of US defense releases.

Access blocked — not collecting

Declared scope only, and access-blocked at the edge. Probed once per endpoint on 2026-08-26 with the project user agent: the site root, the Press Releases and Readouts listing, and robots.txt itself all return HTTP 403 from the edge. An RSS endpoint does answer, but robots.txt cannot be read, so there is no basis on which to say collection is permitted. Collecting only through the one endpoint that happens to answer, while the same edge refuses everything else including the file that would state the rules, would be opportunistic rather than honest.

Limits of this desk, stated plainly

  • Nothing has been configured, enabled or collected.
  • robots.txt returns 403, so this project cannot establish that collection is permitted. That is a blocker on its own, independent of whether any endpoint answers.
  • The institution's current name is U.S. Pacific Command, restored in 2026. If a source is ever built, its identity follows the institution's own name even though the desk stays geographically labeled Indo-Pacific.
  • If it is ever built it is collected under the same contract, health thresholds and evidence hierarchy as every other desk. U.S. institutional statements are evaluated under the same source-verification and editorial standards as every other desk; they are not treated as independent confirmation of their own claims.

These are properties of the desk a reader needs before citing it — see Coverage for what each collection run actually returned.
