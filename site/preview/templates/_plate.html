{# The edition plate: an issue drawn from its own sidecar, in place of a cover photograph (docs/VISUAL_AND_MOTION_SYSTEM.md §3.2). Everything on it is a value the edition itself carries — the series it was published as, its number, the week it covers, and one tick per source-trail entry. A tick is a record the issue listed; it is not a measure of anything else. A model-flagged entry (`is_significant`, the software's triage flag, never the editor's judgment) is drawn in the machine layer's rust and at full height, so the flag reads by shape as well as colour; the others are short and grey. Crimson appears only as the rule at the top: the issue itself is the analysis. Same sidecar in, same plate out: nothing here is random and nothing is invented. An issue with no number draws no numeral; one with no trail draws no ticks. Inline SVG, so it costs a few hundred bytes where the cover PNG it replaces on the home page cost 435 KB. Night Desk ground, because it is a piece of the analysis surface set into the record's page. Measured on #0E1520: rust #D4845F 6.34, grey #5C6570 3.10, and 2.05 between the two. #} {% macro edition_plate(plate, label_id, title_text) -%} {% if plate %} {% set n = plate.ticks | length %} {% set months = ['January','February','March','April','May','June','July','August','September','October','November','December'] %} {% set week = (plate.date[8:10] | int) ~ ' ' ~ months[(plate.date[5:7] | int) - 1] ~ ' ' ~ plate.date[:4] if plate.date else '' %} {% endif %} {%- endmacro %}
